# Support

This is an experimental community project without a public installer release.

- Use GitHub Issues for reproducible bugs and documentation problems.
- Use Discussions for design questions once Discussions are enabled.
- Do not send credentials or device backups.
- Sponsorship does not include personal technical support, a beta entitlement,
  or a guaranteed response time.

If the device cannot boot stock reMarkable OS, stop testing and preserve the
current state before attempting additional writes.
