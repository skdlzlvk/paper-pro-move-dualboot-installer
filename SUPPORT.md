# Support and prebuilt packages

## What is open

The Android runtime in this repository is GPL-3.0. Anyone may inspect, build,
modify and redistribute it under that license. Sponsorship does not remove any
GPL rights, and safety or recovery information is never withheld or weakened to
push people toward sponsoring.

The Android slot's kernel is GPL-2.0. The written corresponding-source offer in
[KERNEL-SOURCE.md](docs/KERNEL-SOURCE.md) is honoured for anyone who receives a
binary, sponsor or not.

## What the US$10/month sponsor tier is for

The maintained Windows package: the installer, the removal tool and the guided
recovery flow, distributed as a versioned build with checksums and release
notes.

- builds tested against the stock firmware versions listed as supported;
- compatibility updates while sponsorship is active — every stock firmware
  release can break the install path, and keeping up with that is the ongoing
  work sponsorship funds;
- priority triage for installation and recovery regressions.

This pays for the proprietary installer, the test hardware, the maintained
builds and the support work. It is not ownership of the open runtime, and it is
not an exclusive license to it. Source and redistribution rights for the
GPL-3.0 runtime published here are unaffected.

A package that has already been downloaded keeps working; it contains no
activation check and cannot remotely disable an installed tablet. What lapses
when sponsorship lapses is access to future maintained downloads.

The package contains no reMarkable firmware, no proprietary reMarkable code, no
Google Mobile Services, no third-party application packages, no device backups,
no access keys and no user data. Third-party software must be obtained through
its own official channel.

## Current availability

The first beta exists and is available to sponsors. It is a beta on purpose:
evidence comes from one developer tablet, and the limits are listed in
[COMPATIBILITY.md](docs/COMPATIBILITY.md).

Sponsorship is not a preorder, a promised release date, or a guarantee that a
modified device cannot fail. Only install on a tablet you are prepared to
restore yourself with reMarkable's official recovery tool.

## Getting help

- Use GitHub Issues for reproducible bugs and documentation problems.
- Do not send credentials or device backups.
- Sponsorship does not guarantee individual technical support or a response
  time.

If the device cannot boot stock reMarkable OS, stop testing and preserve the
current state before attempting further writes.
