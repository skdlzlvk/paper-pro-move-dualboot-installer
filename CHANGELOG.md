# Changelog

All notable public changes to this project will be documented here.

## Unreleased

### Added

- Initial public development snapshot.
- Read-only Windows preflight checks.
- Source for the native Android bootstrap, input relay, controls sidecar,
  OTA guard, and the E Ink-oriented Paper Home application.
- Safety, architecture, source-policy, legal, and release-status documents.
- English and Korean UI resources.
- Device photos and a short Gallery 3 color demonstration.
- A muted 60 fps real-device Paper Home pen-response demonstration.

### Not released

- No partition-writing installer or installable Android image is published yet.
- Recovery, uninstall, backup/restore, and two complete stock OTA-cycle tests
  remain release blockers.
