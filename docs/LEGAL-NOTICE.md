# Project and distribution notice

This document describes the intended project boundary. It is not legal advice.

## Intended public deliverable

The project intends to distribute:

- an open-source Windows installation/recovery/removal tool;
- independently developed integration source;
- documentation, tests, and checksums; and
- project-owned media showing the development device.

## Explicit exclusions

The project does not intend to distribute or sell:

- reMarkable OS or a modified reMarkable OS image;
- reMarkable's proprietary note application, cloud code, or user database;
- device vendor firmware or proprietary device libraries;
- Google Mobile Services or third-party application packages;
- a premodified tablet; or
- user credentials, backups, or personal content.

The future installer is intended to operate on the owner's own device and use
only inputs the user is legally entitled to use. Any required third-party
software must be obtained separately through its authorized channel.

## Sponsorship

GitHub sponsorship is voluntary support for research, installer development,
testing, recovery tooling, and documentation. It is not a purchase, preorder,
software license, support contract, beta entitlement, feature promise, or
guarantee of a release date.

## Independence

This is an independent community project and is not affiliated with, sponsored
by, or endorsed by reMarkable. Compatibility references do not imply
endorsement.

Before distributing an installer or payload, the final source, dependency,
trademark, warranty, and regional distribution position should receive
qualified legal review.
